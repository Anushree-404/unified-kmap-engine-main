# AGROVA AI — Frontend

The AGROVA AI frontend is a **TanStack Start** (React 19 + TypeScript + Vite + Tailwind CSS v4) full-stack SSR application. It includes both the browser UI and server functions that run at the edge.

---

## Technology Stack

| Layer | Technology |
|-------|-----------|
| Framework | [TanStack Start](https://tanstack.com/start) 1.x (full-stack SSR) |
| UI library | React 19 |
| Language | TypeScript 5 |
| Build tool | Vite 8 |
| Styling | Tailwind CSS v4 + `tw-animate-css` |
| UI primitives | Radix UI + shadcn/ui |
| Routing | TanStack Router (file-based) |
| Data fetching | TanStack Query v5 |
| Forms | React Hook Form + Zod |
| Charts | Recharts |
| Icons | Lucide React |
| Package manager | Bun |
| Server runtime | Nitro (Cloudflare Workers target) |

## Setup

```bash
cd FRONTEND
cp .env.example .env
# Fill in your Google Maps API key in .env

# Install dependencies (Bun recommended)
bun install
# or: npm install
```

## How the ML Models Are Used

The frontend embeds two ML models as static data:

1. **Crop recommendation** (`src/data/crop-model.ts`): a serialised Random Forest (80 trees) trained by `ML_MODEL/training/train_crop_model.py`. The file is regenerated by running that script. Client-side inference runs in `src/lib/crop-recommendation.ts`.

2. **Weather forecasting** (`src/data/weather-model.json`): a ridge regression model trained by a separate offline process. Server-side inference runs in `src/lib/forecast.server.ts` (a TanStack Start server function — not exposed to the browser).

To regenerate the crop model after retraining:
```bash
cd ../ML_MODEL
python training/train_crop_model.py
# The script writes directly to FRONTEND/src/data/crop-model.ts
```

## Environment Variables

| Variable | Purpose | Required |
|----------|---------|----------|
| `VITE_LOVABLE_CONNECTOR_GOOGLE_MAPS_BROWSER_KEY` | Google Maps JS API key (browser) | Yes for KMap |
| `VITE_LOVABLE_CONNECTOR_GOOGLE_MAPS_TRACKING_ID` | Lovable connector tracking ID | Yes for KMap |
| `VITE_API_BASE_URL` | External Python backend base URL | Optional |

Server-only secrets (never exposed to the browser):
| Variable | Purpose |
|----------|---------|
| `LOVABLE_API_KEY` | Lovable connector auth for server-side Google Maps calls |
| `GOOGLE_MAPS_API_KEY` | Server-side Google Maps geocode / elevation key |
