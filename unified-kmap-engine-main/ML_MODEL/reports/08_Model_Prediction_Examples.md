### 1.5 How to Run Actual Predictions

**Using the AGROVA AI frontend (demo page):**

1. Visit the running app at `http://localhost:3000/demo`
2. Enable "Auto Location Toggle" or manually set field parameters
3. The Random Forest model runs entirely in the browser
4. Top 5 crops are displayed with percentage match scores

**Using the FastAPI backend:**

```bash
curl -X POST http://localhost:8000/api/crop/recommend \
  -H "Content-Type: application/json" \
  -d '{"nitrogen":90,"phosphorus":42,"potassium":43,"temperature":20.88,"humidity":82.0,"ph":6.5,"rainfall":202.94}'
```

Expected response:
```json
{
  "recommendations": [
    { "crop": "rice", "score": 91.0 },
    { "crop": "papaya", "score": 3.0 },
    { "crop": "mango", "score": 2.0 }
  ],
  "model": "Random Forest Crop Classifier v1",
  "validation_accuracy": 0.9955
}
```

**Using the inference CLI:**

```bash
python ML_MODEL/inference/crop_inference.py \
  --N 90 --P 42 --K 43 \
  --temperature 20.88 --humidity 82.0 --ph 6.5 --rainfall 202.94
```

## 2. Weather Forecast — Prediction Examples

The weather model is a ridge regression running server-side in `forecast.server.ts`. Predictions require live weather history from Open-Meteo as input; they cannot be reproduced without a running server.

### 2.1 Model Output Structure

For any lat/lon in the five Coastal Karnataka taluks:

```json
{
  "days": [
    { "date": "2026-11-04", "tMax": 32.1, "tMin": 24.3, "rain": 0.0, "humidity": 78 },
    { "date": "2026-11-05", "tMax": 31.8, "tMin": 24.1, "rain": 1.2, "humidity": 81 },
    ...
  ],
  "accuracy": [
    { "variable": "Max temperature", "mae": 1.05, "unit": "°C" },
    { "variable": "Min temperature", "mae": 0.78, "unit": "°C" },
    { "variable": "Daily rainfall",  "mae": 7.60, "unit": "mm" },
    { "variable": "Humidity",        "mae": 5.03, "unit": "%" }
  ]
}
```

The MAE values shown are the Day-7 hold-out MAE from `weather-model.json` — **actual verified values**.

## 4. Advisory Chatbot — Sample Interactions

The `AgronomistChat` component responds to keywords in English and Kannada.

| User Input | Bot Response (English) |
|-----------|----------------------|
| "Which crop suits my field?" | Provides crop selection guide based on soil type and rainfall |
| "Leaf spot disease" | Recommends Mancozeb 75% WP spray + neem oil alternative |
| "rice" | Provides paddy-specific fertilizer, water management, and pest control advice |
| "water irrigation drip" | Advises drip irrigation + mulching saves 40% water |
| "loan scheme" | Explains Kisan Credit Card (KCC) @ 4% interest, documents required |
| "hello" | Greeting in English and Kannada, lists available topics |

The chatbot is a **rule-based system** — no ML model is involved.
